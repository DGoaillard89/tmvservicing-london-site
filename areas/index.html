The map, sort of

Five patches, 33 local authorities, one team.

We split London into five patches so we can plan rounds sensibly and keep engineers working in the same part of town. It's our way of organising the work, not an official boundary, so if you're near a border, don't worry about which page you're on. We cover you either way.

The postcode districts listed are the main ones for each borough. Postcodes and borough boundaries don't line up neatly (London never does), so if yours isn't listed, it's almost certainly still covered. Just ask.

Why London-only

Staying inside the M25 is a feature, not a limitation.

Close by

Our engineers start the day in London, not two counties away. Return visits for no-access flats are easier to fit in.

Used to the water

London's hard water is what we deal with every day, so descaling and strainer cleaning are part of the job, not an extra.

Used to the buildings

Mansion blocks, converted terraces, estates, towers and listed buildings. We know where TMVs tend to hide in each.

Used to the parking

CPZs, red routes and loading bays get planned before the visit, so the time you pay for is time spent on valves.
